# ⚙️ MentorLagbe — Server

MentorLagbe Server is the backend API for MentorLagbe, a tuition management platform that connects students with tutors. It manages application data, user operations, tuition posts, and subscription payments.

## 🌐 Live API

[Visit MentorLagbe API](https://mentorlagbe-server-1z6g.onrender.com)

## 🔐 Admin Credentials

- **Email:** admin@mail.com
- **Password:** adminpassword

## ✨ Key Features

- 🔌 RESTful API architecture.
- 🗄️ MongoDB database integration.
- 🔑 Authentication integration with Better Auth.
- 👥 Role-based access for Students, Tutors, and Admins.
- 📚 Tuition creation, retrieval, updating, and moderation.
- 📝 Student application management.
- 📊 Dashboard statistics and management endpoints.
- 💳 Stripe Checkout session creation.
- 🔔 Stripe webhook integration for payment verification.
- 💰 Payment record management and subscription updates.
- 🛡️ Input validation and error handling.
- 🌍 Environment-based configuration and CORS support.

## 🛠️ Technologies & npm Packages

- Node.js
- Express.js
- mongodb
- better-auth
- stripe
- dotenv
- cors
- nodemon

## 📦 Installation

```bash
git clone YOUR_SERVER_REPOSITORY_URL

```
